## 📋 Descripción

Proyecto de streaming interactivo que combina **Minecraft** con **TikTok LIVE**. Incluye sistema de regalos virtuales, animaciones en tiempo real y experiencia interactiva para los viewers.

## ✨ Funcionalidades

- 🎮 Streaming de Minecraft (PaperMC + TLauncher)
- 📱 Integración con TikTok LIVE
- 🎁 Sistema de regalos virtuales
- 🎨 Animaciones en tiempo real
- 📜 Términos de uso completos

## 📄 Términos de Uso

La página principal (`index.html`) contiene los términos de uso completos de la plataforma.

## 🛠️ Tecnologías

- HTML5 + CSS3
- JavaScript
- Minecraft PaperMC
- TikTok LIVE API
